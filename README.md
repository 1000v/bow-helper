# Bow & Hitbox Helper (Minecraft 1.16.5 Client Mod)

Легковесный клиентский мод для Minecraft 1.16.5 на базе **Fabric Loader**.

## Возможности
1. **Быстрое переключение хитбоксов:** клавиша `B` включает/выключает рамки коллизий сущностей напрямую без открытия отладочного экрана `F3`.
2. **HUD помощника стрельбы из лука:** когда игрок держит лук в руке, в левом верхнем углу отображаются:
   - Азимут (Yaw в градусах 0–360°);
   - Возвышение (Pitch в градусах);
   - Процент натяжения тетивы и начальная скорость стрелы $V_0$.
3. **Общий выключатель HUD:** клавиша `H` (включает/выключает отображение интерфейса).

## Автоматическая сборка на GitHub (без установки Java на ПК)

1. Залей этот репозиторий на свой GitHub:
   ```bash
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```
2. Открой вкладку **Actions** в репозитории на GitHub.
3. Дождись завершения автоматической сборки (зеленая галочка `Build Fabric 1.16.5 Mod`).
4. Нажми на завершённую сборку и в самом низу в блоке **Artifacts** скачай архив **`BowHitboxHelper-1.16.5`**.

---

## Установка в игру

1. В лаунчере (TLauncher, Prism, официальный) выбери версию **`Fabric 1.16.5`**.
2. Помести скачанный `.jar` файл в папку `.minecraft/mods`.
3. Убедись, что в папке `mods` также лежит библиотека **Fabric API** для 1.16.5.
4. Запусти игру.
