# Bow & Hitbox Helper (Minecraft 1.16.5 Client Mod)

Легковесный клиентский мод для Minecraft 1.16.5 на базе **Fabric Loader**.

## Возможности
1. **3D Дуга полёта стрелы в мире:** при удержании лука прямо в игровом мире рисуется плавная 3D-траектория полёта стрелы с расчётом гравитации и сопротивления воздуха. На месте столкновения с блоком ставится цветной 3D-маркер приземления.
2. **Динамический прицел (Crosshair Charge Indicator):** по центру экрана вокруг перекрестия отображается анимация натяжения лука (проценты и сходящиеся скобки), загорающаяся ярко-зелёным цветом (`§a[ ● ] MAX`) ровно при 100% готовности к критическому выстрелу.
3. **Многослотовые метки пристрелки (5 слотов):**
   - Клавиша **`N`** — переключает активный слот метки (от 1 до 5);
   - Клавиша **`K`** — сохраняет текущий угол и позицию в выбранный слот;
   - На HUD отображается номер слота и доводка: `[Метка 1/5] вправо +2.1°, подними +0.8°`;
   - Клавиша **`J`** — сбрасывает метку текущего слота.
4. **Умный помощник попадания (Ballistics Advisor):** рассчитывает реальную физику стрелы до блока/цели в прицеле и подсказывает необходимый угол возвышения (`▲ Подними на +X.X°` или `✔ ИДЕАЛЬНЫЙ УГОЛ`).
5. **Дальномер до цели:** точная дистанция в блоках в верхнем левом углу.
6. **Armor & Hand HUD:** клавиша **`U`** включает отображение прочности брони и оружия с цветовыми индикаторами износа.
7. **Быстрое переключение хитбоксов:** клавиша **`B`** включает/выключает хитбоксы сущностей без отладочного экрана $F3$.
8. **Общий выключатель оверлеев и траектории:** клавиша **`H`**.

---

## Горячие клавиши по умолчанию

| Клавиша | Действие |
| :--- | :--- |
| **`B`** | Вкл/выкл хитбоксы |
| **`H`** | Вкл/выкл HUD и 3D-траекторию |
| **`N`** | Переключить слот метки (1 → 2 → 3 → 4 → 5) |
| **`K`** | Запомнить угол в текущий слот |
| **`J`** | Сбросить текущую метку |
| **`U`** | Вкл/выкл Armor & Hand HUD |

*(Все клавиши можно изменить в стандартном меню игры: Настройки → Управление).*

## Автоматическая сборка на GitHub

При пуше в репозиторий GitHub Actions автоматически компилирует мод и выкладывает готовый `.jar` в раздел **Actions → Artifacts**.
