# Bow & Hitbox Helper (Minecraft 1.16.5 Client Mod)

Легковесный клиентский мод для Minecraft 1.16.5 на базе **Fabric Loader**.

## Возможности
1. **Быстрое переключение хитбоксов:** клавиша `B` включает/выключает рамки коллизий сущностей напрямую без отладочного экрана `F3`.
2. **HUD помощника стрельбы из лука (вверху слева):**
   - **Азимут (Yaw 0–360°)** и **Возвышение (Pitch)**;
   - **Дальномер:** точная дистанция до блока/игрока в прицеле;
   - **Умная подсказка попадания (Ballistics Advisor):** рассчитывает физику стрелы с учётом расстояния и перепада высоты, показывает точный рекомендуемый угол наклона (`▲ Подними на +X.X°` или `✔ ИДЕАЛЬНЫЙ УГОЛ`);
   - **Процент натяжения тетивы** и начальная скорость $V_0$.
3. **Метки пристрелки (Angle Bookmarks):**
   - Клавиша `K` — запоминает текущий угол и позицию (например, пристрелялся по мосту врага на Bedwars);
   - На HUD отображается разница: `ΔYaw` (доверни влево/вправо) и `ΔPitch` (подними/опусти);
   - Клавиша `J` — сброс сохранённой метки.
4. **Armor & Hand HUD (Индикатор брони и оружия):**
   - Клавиша `U` — переключает отображение прочности надетой брони и предмета в руках;
   - Цветной статус: зеленый (>50%), желтый (20-50%), красный (<20% с предупреждением ⚠).
5. **Общий выключатель HUD лука:** клавиша `H`.

---

## Горячие клавиши по умолчанию

| Клавиша | Действие |
| :--- | :--- |
| **`B`** | Вкл/выкл хитбоксы |
| **`H`** | Вкл/выкл HUD прицеливания |
| **`K`** | Запомнить угол (пристрелочная метка) |
| **`J`** | Сбросить пристрелочную метку |
| **`U`** | Вкл/выкл Armor & Hand HUD |

*(Все клавиши можно изменить в настройках игры: Настройки → Управление).*

## Автоматическая сборка на GitHub

При пуше в репозиторий GitHub Actions автоматически компилирует мод и выкладывает готовый `.jar` в раздел **Actions → Artifacts**.
